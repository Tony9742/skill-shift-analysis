# 研究设计文档（第一阶段）

## 1. 研究问题与分析单位

- **RQ1**：招聘岗位描述中「AI 相关技能」的词频随时间如何变化？
- **RQ2**：初级岗位与高级岗位的技能要求变化是否分化？
- **RQ3**：哪些传统技能在贬值、哪些新兴技能在升值？

**分析单位**：单条招聘启事（job posting）。核心观测为「该岗位是否提及技能 s」与「技能 s 在时期 t 的岗位渗透率」。

## 2. 技能分类框架

以 **O\*NET** 的技能分类为主框架，结合《中华人民共和国职业分类大典（2022 年版）》的本土化表述，构建三层技能词典：

| 层级 | 类别 | 示例关键词（初版，第二阶段扩充） |
|---|---|---|
| **A. AI/数据技能** | A1 AI 核心 | 机器学习、深度学习、神经网络、NLP、计算机视觉、大模型/LLM、AIGC、强化学习 |
| | A2 AI 工具链 | TensorFlow、PyTorch、Keras、scikit-learn、Hugging Face、LangChain、Prompt |
| | A3 数据工程 | Hadoop、Spark、Flink、Hive、Kafka、ETL、数据仓库 |
| **B. 通用数字技能** | B1 编程语言 | Python、R、SQL、Java、Scala |
| | B2 分析与可视化 | Excel、SPSS、SAS、Tableau、Power BI、数据透视表 |
| **C. 传统/软技能** | C1 传统办公 | Office、PPT、Word、报表制作 |
| | C2 软技能 | 沟通、团队协作、逻辑思维、抗压（作对照组，检验「词频上升」是否为整体文本膨胀所致） |

设计要点：
1. **词典构建方法**：种子词（上表）→ jieba 分词 + 词频排序人工审核扩充 → 别名扩展，三轮迭代后冻结词典，保证各时期使用同一标准。**（已于 2025-10-05 完成并冻结为 v1.0：7 组 62 个技能，机器可读词典见 `src/skill_dictionary.json`，构建与验证记录见 `docs/skill_dictionary.md` 和 `notebooks/03_skill_dictionary.ipynb`。）**
2. **C 组作安慰剂对照**：若软技能词频也同比例上升，说明存在「职位描述越写越长」的测量趋势，需用相对份额（技能词频 / 全部技能词频）而非绝对词频。**（已在 2018→2023 同口径数据上验证：含安慰剂组在内的所有组绝对渗透率普遍上升，证实相对份额是必要的，见 notebook 03 第 4 节。）**
3. **贬/升值的操作化定义**（RQ3）：技能 s 的「价值变化」= 后期渗透率 − 前期渗透率，辅以提及该技能的岗位平均薪资变化作交叉验证。

## 3. 初级 / 高级岗位判定规则

以**工作经验要求**为主判据，职位名称关键词与薪资为辅助校验：

| 层级 | 主判据（workYear 字段） | 辅助判据 |
|---|---|---|
| 初级（Junior） | 应届毕业生、1年以下、1-3年 | 职位名含「助理/专员/初级/Junior/实习」；薪资中位数 < 样本当期 25 分位 |
| 中级（Mid） | 3-5年 | 不满足初级或高级条件 |
| 高级（Senior） | 5-10年、10年以上 | 职位名含「高级/资深/专家/负责人/主管/总监/Lead/Senior/Principal」 |

规则说明：
- 「不限」单独成组，不并入初级（探查显示其薪资分布明显低于 1-3 年组，合并会污染初级组）。
- 主判据缺失时启用辅助判据；两者冲突时以 workYear 为准（平台结构化字段比自由文本更可靠）。
- 数据探查提示初级组样本偏薄（应届仅 2.7%），正式分析时将「应届 + 1年以下 + 1-3年」合并为初级组，并在报告中披露组间样本量差异。

## 5. 效度威胁与对策

| 威胁 | 对策 |
|---|---|
| 各时期数据来源口径不一致（不同平台/采集方式） | 分来源分别估计趋势，只在口径一致的数据内部做时间比较；跨来源比较时明确标注 |
| 职位描述文本长度随时间系统性变长 | 使用相对份额与安慰剂对照组 |
| 平台曝光机制导致在架岗位非随机样本 | 限定采集窗口；报告中披露幸存者偏差 |
| **文本字段类型跨期不同**（2018/2023 为描述全文，2025 为结构化技能标签，后者更浓缩，基础技能渗透率系统性偏低） | 跨期比较只作趋势方向参考；RQ2/RQ3 的量化结论以 2025 年 11 万行数据集**内部**的分组对比为主 |
| ~~早期数据无 AI 浪潮后的对照期~~（已解决） | 2025-10-05 已补充 Kaggle 数据：2020（519）、2023（437）、2025（110,176），时间序列骨架为 2017/2018 → 2020 → 2023 → 2025 |

> **2025-10-05 可行性更新**：2025 年数据集经验/学历/薪资/技能标签齐全（技能标签零缺失），按第 3 节规则可分出初级 30,393 / 中级 48,756 / 高级 28,432，样本量充足，RQ2 的层级分化分析可直接在该数据集内部进行（预演见 `notebooks/02_kaggle_data_profiling.ipynb`）。该数据集经验标签体系与 2017/2018 基线不同（「3年及以上」vs「3-5年」），映射规则见 notebook 02 的 `判定层级` 函数。

## 6. 伦理与合规

- 仅使用公开授权数据集，不爬取商业招聘平台（红线见 `data_acquisition_plan.md`）。
- 数据不含求职者个人信息；公司名仅在聚合层面使用，不做单一企业画像。
- 所有代码、词典与判定规则公开在仓库中，保证可复现。
