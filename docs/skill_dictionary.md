# 技能分类词典说明（v1.0，已冻结）

> 词典文件：`src/skill_dictionary.json`（机器可读，含别名与匹配规则）
> 应用代码：`src/build_skill_matrix.py`；构建过程与验证：`notebooks/03_skill_dictionary.ipynb`

## 1. 构建方法（三轮迭代后冻结）

1. **种子词**：来自 `docs/research_design.md` 的三层技能分类框架（以 O\*NET 技能分类为主框架，结合《中华人民共和国职业分类大典（2022 年版）》本土化表述）。
2. **语料校准**：对 2018 杭州（431 条）与 2023 南昌（437 条）职位描述全文做 jieba 分词，统计高频词 Top30/Top60，人工审核：
   - 收入：SQL、Python、数据挖掘、数据仓库、统计学、建模、大数据、可视化等语料中真实高频的技能词；
   - 排除：「业务/能力/团队/产品/需求/项目」等高频但非技能的噪声词。
3. **别名扩展**：为每个技能补充中英文别名与缩写（如 机器学习 = 机器学习 / machine learning / ML），冻结后**各时期统一使用同一词典**，保证跨期可比。

## 2. 结构总览（7 组 62 个技能）

| 分组 | 说明 | 技能示例 |
|---|---|---|
| A1_AI核心 | 人工智能核心方法 | 机器学习、深度学习、神经网络、NLP、计算机视觉、数据挖掘、大模型与生成式AI（LLM/AIGC/GPT/Agent/RAG…）、推荐系统、知识图谱、语音识别 |
| A2_AI工具链 | AI 框架与工具 | TensorFlow、PyTorch、Keras、scikit-learn、XGBoost、LightGBM、OpenCV、HuggingFace、LangChain、Transformer 架构 |
| A3_数据工程 | 大数据平台与基础设施 | Hadoop、Spark、Flink、Hive、Kafka、数据仓库、ETL、数据库、Elasticsearch、ClickHouse、大数据 |
| B1_编程语言 | 通用编程与查询语言 | Python、SQL、Java、R、Scala、C++、Golang、JavaScript、Shell |
| B2_分析与可视化 | 统计分析与 BI 工具 | Excel、SPSS、SAS、Tableau、PowerBI、FineBI、数据透视表、统计建模、可视化 |
| C1_传统办公 | 传统办公软件 | Office、PPT、Word、WPS、Visio、报表制作 |
| C2_软技能_安慰剂对照 | 软技能（对照组） | 沟通、团队协作、逻辑思维、责任心、抗压、学习能力 |

## 3. 匹配规则

| 规则 | 适用 | 示例 |
|---|---|---|
| `包含`（默认） | 中文词与不歧义的长英文词，大小写不敏感子串匹配 | 机器学习、pytorch、mysql |
| `边界` | 短/易误伤的英文词，正则前后边界限定（前后不允许字母、数字、`+`、`#`、`.`） | `java` 不会命中 javascript；`R` 不会命中普通单词 |
| `大小写敏感` | 单字母或全大写缩写 | `R`（R 语言）、`SAS`（避免命中小写 sas 片段） |

已知边界情况（接受并记录）：子串匹配不区分语义角色，「不需要 XX 经验」这类否定语境仍会命中，预计占比很小；`ML/DL/CV` 等缩写在中文文本中歧义低。

## 4. 词典产出

- `data/processed/skill_matrix_<年份>.csv` 与 `skill_matrix_all.csv`：116,594 条岗位记录 × 75 列（6 个元数据列 + 62 个技能 0/1 列 + 7 个分组命中列）。
- 层级判定统一为「最小年数规则」：经验要求 ≤1 年（含应届/在校/无需经验）→ 初级；2-4 年 → 中级；≥5 年 → 高级；「不限」剔除。实现见 `src/build_skill_matrix.py` 的 `判定层级`。

## 5. 验证结果（详见 notebook 03）

1. **抽查无误伤**：`R语言` 命中的原文均为真实 R 语言语境（如「SAS、R、python」）。
2. **安慰剂组行为符合预期**：2018→2023 全文口径下所有组（含软技能）绝对渗透率普遍上升，证实跨期比较必须用相对份额。
3. **2025 年层级差异显著**：AI 核心渗透率 初级 5.42% > 中级 4.41% > 高级 3.69%，卡方检验 χ²=107.5，p=4.5e-24。
