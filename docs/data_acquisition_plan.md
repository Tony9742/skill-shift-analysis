# 数据获取方案（候选公开来源清单）

> 背景：Kaggle 的数据下载必须登录账号（API 需 `~/.kaggle/kaggle.json` 凭证），本机未配置。
> 按项目约定不绕过登录限制，故本阶段改用 GitHub 公开数据集完成流程搭建，
> 同时整理以下候选来源，供后续阶段（尤其是补充 2020 年后数据）使用。

## 候选来源一览

| # | 来源 | 内容 | 时间覆盖 | 获取方式 | 门槛/风险 |
|---|---|---|---|---|---|
| 1 | **Kaggle：Lagou Tech Jobs Scraper Data**（kaggle.com/datasets/logiover/lagou-tech-jobs-scraper-data） | 拉勾网技术岗位样本 | 近年 | 注册 Kaggle 账号 → 数据集页面直接下载，或配置 API key 后 `kaggle datasets download` | 需注册登录；样本量小（约 100 行示例），可作补充 |
| 2 | **Kaggle 站内搜索**（关键词：拉勾 / lagou / 招聘 / job posting China） | 中文招聘类数据集若干 | 多为 2017–2021 | 同上 | 需注册登录；需逐个核对时间范围与字段质量 |
| 3 | **和鲸社区（heywhale.com）数据集** | 如「拉勾招聘 2 万多条技术岗位招聘数据」 | 近年 | 注册和鲸账号后在线使用或下载 | 需注册；部分数据集仅限站内 Notebook 环境使用 |
| 4 | **GitHub 公开仓库**（本阶段已采用） | xucoolboy/Data_job_in_lagou：2017 全国 + 2018 杭州拉勾数据 | 2017–2018 | 直接下载，无需登录（脚本：`src/download_data.py`） | 无 LICENSE，仅限学术研究用途；时间偏早 |
| 5 | **学术论文共享数据 / 各高校开放数据平台**（如北大开放研究数据平台、清华数据堂） | 部分劳动经济学研究公开的招聘文本数据 | 视具体研究 | 平台注册后申请/下载 | 需核对授权条款，申请周期不定 |
| 6 | **O*NET / Lightcast 等海外技能数据库**（onetcenter.org） | 职业技能分类与任务描述（非岗位招聘数据） | 持续更新 | 官网公开下载，无需登录 | 英文体系，仅作技能分类框架参照，不作岗位样本 |

## 后续阶段建议

1. **最优先**：注册 Kaggle 账号，检索并下载 2020 年后（尤其 2023–2025）的中文/英文招聘数据集，与本阶段的 2017–2018 基线构成时间序列。找到候选后可把 API key 放到 `~/.kaggle/kaggle.json`，我即可用脚本自动下载。
2. 若 Kaggle 上找不到合适的近年中文数据，可转向英文招聘数据集（如 LinkedIn/Indeed 的历史公开 dump），把研究问题改为跨国比较视角，同样能支撑硕士申请作品集。
3. 任何需要付费或授权条款不明的数据源，先停下来讨论，不擅自获取。

## 合规红线（项目全程有效）

- **不爬取** BOSS 直聘、前程无忧（51job）、智联招聘等商业平台（违反服务条款，存在法律风险）。
- 仅使用：已公开的数据集、有明确学术授权的数据、官方开放接口。
